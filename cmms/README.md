# سامانه مستقل تعمیرات و نگهداری مهرسا (CMMS)

این برنامه در مسیر `/cmms/` توسعه داده می‌شود و فایل اصلی سامانه درخواست خرید (`/index.html`) را تغییر نمی‌دهد.

## معماری فعلی
- رابط کاربری مستقل در `cmms/index.html`
- احراز هویت از طریق Supabase Auth موجود
- نقش‌ها و سطح دسترسی از جداول CMMS موجود در پروژه Production خوانده می‌شوند
- عملیات از RPCهای کنترل‌شده و سیاست‌های RLS سمت پایگاه داده استفاده می‌کنند
- قابلیت نصب PWA از طریق `manifest.webmanifest`

## مرزهای استقلال
- هیچ فایل یا رکوردی از ماژول درخواست خرید در این مسیر تغییر نمی‌کند.
- ماژول CMMS فعلاً از همان پروژه Supabase استفاده می‌کند تا حساب‌های کاربری و داده‌های CMMS دوباره‌کاری نشوند.
- اتصال به درخواست خرید (برای مثال تبدیل دستورکار به درخواست خرید) در مرحله یکپارچه‌سازی بعدی انجام خواهد شد.

## وضعیت تحویل
این مسیر، نسخه توسعه مستقل است؛ قبل از انتشار عمومی باید آزمون مرورگر با حساب‌های واقعی، کنترل دسترسی هر نقش، ثبت/ویرایش عملیات، بارگذاری فایل شواهد و آزمون موبایل انجام شود.
